# Security boundaries

This is a fictional, synthetic-data prototype. It has no production authentication, payment execution, customer messaging, or live provider transport. CLI customer/actor flags and browser ownership controls are simulation inputs, not security identities. Do not connect real orders, customers, financial services or credentials.

Replay misses and integrity failures stop explicitly. Record/live modes are disabled. The browser contains public synthetic fixtures and must never be treated as a private data store. Approval records authorization only; no financial operation occurs.

Phrase-based validation, money parsing and language detection have bounded coverage. Passing the synthetic checks is not a security guarantee or evidence of model reliability. For code issues, use the repository's private vulnerability reporting feature if available; do not include secrets or personal data in public issues.
